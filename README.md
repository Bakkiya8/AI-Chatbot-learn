deployed using streamlit web deploy option passimg API key from the Streamlit Cloud

 1.Go to share.streamlit.io
2. Click "Sign in with GitHub" — use the same account
3. Click "New app" (top right)
4. Fill in the form:
   Repository  →  repo name
   Branch      →  main
   Main file   →  xx.py
5. Click "Deploy!"
